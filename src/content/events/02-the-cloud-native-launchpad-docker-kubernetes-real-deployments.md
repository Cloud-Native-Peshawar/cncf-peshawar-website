## About This Event

The Cloud Native Launchpad: Docker, Kubernetes & Real Deployments Join Cloud Native Peshawar, a CNCF Community Group, for an interactive hands-on webinar designed to introduce students and aspiring technology professionals to the world of Cloud Native Computing, Containers, and Kubernetes. Cloud Native technologies power many of the world's most widely used applications and platforms. Organizations increasingly rely on containers, Kubernetes, and modern infrastructure practices to build scalable, resilient, and efficient systems. This session aims to demystify these concepts and provide participants with a practical understanding of how modern applications are deployed and managed. During this workshop, participants will explore the fundamentals of Cloud Native architecture, understand the role of containers and Docker, and learn the core building blocks of Kubernetes, including Pods, Deployments, and Services. The session will feature a live demonstration where a sample application is deployed to Kubernetes from scratch, showcasing concepts such as scaling, self-healing, and basic troubleshooting. What You'll Learn Introduction to Cloud Native Computing and the CNCF ecosystem Why organizations use containers and Kubernetes Docker fundamentals and containerization concepts Kubernetes architecture and key resources Pods, Deployments, Services, and declarative configuration Scaling and self-healing applications Debugging common deployment issues Cloud Native learning paths and CNCF certifications Live Hands-On Demonstration Participants will observe a complete Kubernetes deployment workflow, including: Writing Kubernetes YAML manifests Deploying a sample application Exposing applications through Services Scaling workloads across multiple replicas Understanding Kubernetes self-healing capabilities Troubleshooting and resolving common errors Who Should Attend? Computer Science, Software Engineering, IT, and AI students Beginners interested in Cloud Computing and DevOps Aspiring Cloud, Platform, and DevOps Engineers Open-source enthusiasts and CNCF community members Anyone curious about Kubernetes and modern application deployment Event Details 📅 Date: Friday, October 9, 2026 ⏰ Time: 7:00 PM – 9:00 PM PKT 🌐 Format: Virtual (Google Meet) Whether you are taking your first steps into Cloud Native technologies or looking to strengthen your Kubernetes foundations, this session will provide practical insights, real-world demonstrations, and a clear roadmap for further learning.
